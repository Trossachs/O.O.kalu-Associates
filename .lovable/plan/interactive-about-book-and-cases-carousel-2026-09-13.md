# Interactive About Book and Cases Carousel

## Overview
Add two focused homepage experiences while preserving Equity Chambers’ existing Nigerian visual identity, typography, imagery, and motion language.

## What will be built

### 1. 3D “About Us” book
- Insert a new About section immediately after “The Bench.”
- Present a closed, clothbound hardcover labeled “About Us,” with restrained brass detailing.
- As the section enters view, animate the cover opening in perspective and settle into an accessible two-page spread.
- Place a dignified founder portrait of **O.O. Kalu, Esq.** on the left page.
- Add polished legacy-and-vision copy on the right page, grounded in the firm’s Nigerian commercial and disputes practice.
- Provide a reduced-motion version that shows the spread directly, plus a compact stacked treatment on small screens.

### 2. Notable Cases slideshow
- Replace the current homepage case list with a horizontal carousel showing one principal matter at a time.
- Include previous/next controls, position indicators, and touch/drag navigation.
- Add the requested practice symbols to each case card: ⚖️ litigation, 🏢 corporate/M&A, 🚢 maritime, ⚡ energy, and 🏦 banking/finance, with sensible equivalents for other existing categories.
- Preserve year, title, outcome, and the link to the full Notable Cases page.
- Keep navigation keyboard-accessible and motion restrained.

## Visual assets
- Generate a realistic, editorial founder portrait consistent with the existing attorney photography.
- Keep all current photos and portraits unchanged.

## Technical details
- Build the book as a focused React component using CSS 3D transforms and intersection-driven progress; no heavy 3D engine is needed.
- Build the cases carousel with the project’s existing Embla dependency and semantic controls.
- Use existing semantic color tokens and cinematic easing.
- Validate the homepage at desktop and mobile sizes, including scroll activation, carousel controls, reduced motion, and console cleanliness.
